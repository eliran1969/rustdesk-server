## מה נשאר לבדוק אצלך

לבצע אחרי התקנת הניסיון ב-Synology לפי `docs/webconsole/synology-upgrade.md`.

- [ ] ב-client על מחשב אחד: הגדרות, שרת API, הכתובת `http://<synology-ip>:21114`.
- [ ] תוך כ-30 שניות המכשיר מופיע בעמוד המכשירים עם נקודה ירוקה.
- [ ] סוגרים את ה-client ותוך כ-30 שניות הנקודה הופכת לאפורה.
- [ ] ב-client: Login עם המשתמש admin. ה-client מציג את שם המשתמש, ובקונסול העמודה "משתמש משויך" מציגה admin.
- [ ] יוצאים מהחשבון ב-client, והשיוך נשאר בקונסול.
- [ ] מתחברים 11 פעמים עם סיסמה שגויה ומקבלים הודעת חסימה.
- [ ] חיבור מרחוק רגיל בין שני מחשבים עובד כמו לפני השדרוג.
- [ ] בדפדפן: מעבר בין עברית לאנגלית מהפך את כיוון הממשק (ימין לשמאל ולהפך).

## איך מריצים שוב את הבדיקה האוטומטית

מתוך תיקיית הפרויקט (דורש Rust, ו-Python 3; אם `console-ui/dist` חסר הסקריפט בונה אותו):

```
python -I docs/webconsole/phase1-acceptance-check.py
```

בלי בנייה מחדש (אם כבר נבנה):

```
python -I docs/webconsole/phase1-acceptance-check.py --skip-build
```

הסקריפט מפעיל שרת זמני על פורטים 21114 עד 21119, לכן צריך לוודא שאין hbbs/hbbr אחרים רצים. הוא מדפיס PASS או FAIL לכל בדיקה ומוחק אחריו את הקבצים הזמניים. הסקריפט משתמש גם ב-`E:\RustDesk\res\devices.py` ואפשר לשנות נתיב עם `--devices-py`.
