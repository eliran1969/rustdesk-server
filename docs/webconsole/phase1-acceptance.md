# בדיקת קבלה - שלב 1 של ה-Web Console

תאריך הרצה: 2026-11-15

הבדיקה האוטומטית מדמה client של RustDesk מול שרת hbbs מקומי וזמני (תיקייה זמנית, בלי לגעת ב-RustDesk המותקן במחשב ובלי לגעת ב-Synology). בדיקות עם מכשירים אמיתיים מופיעות ברשימה הידנית בהמשך.

הסברים למונחים: sysinfo הוא פרטי המחשב ש-client שולח (שם, מערכת הפעלה). heartbeat הוא "אני חי" שנשלח כל כמה שניות. uuid הוא מזהה סודי של ה-client. access_token הוא "כרטיס כניסה" אחרי התחברות. 401 פירושו "לא מחובר", ו-429 פירושו "יותר מדי ניסיונות, חסום זמנית". `must_change_password` פירושו שחובה להחליף סיסמה בכניסה הראשונה. ports הם "דלתות" ברשת שהשרת מאזין בהן.

מה שלא ניתן לבדוק אוטומטית: ה-client האמיתי לא הופעל (בכוונה). הרישום של client ל-hbbs דומה בסימולציה ע"י הוספת שורה ישירות ל-DB.

## מה נשאר לבדוק אצלך

לבצע אחרי התקנת הניסיון ב-Synology לפי `docs/webconsole/synology-upgrade.md`.

- [ ] את סיסמת ה-admin ההתחלתית מוצאים בלוג של ה-container ב-Synology: Container Manager, בוחרים את ה-container, לשונית Log, ומחפשים את השורה `Console initial admin password: ...`.
- [ ] בכניסה הראשונה לקונסול עם הסיסמה הזו, המערכת מחייבת להחליף סיסמה לפני שממשיכים.
- [ ] ב-client על מחשב אחד (הגדרות, רשת, ID/Relay server, שדה API Server): הגדרות, שרת API, הכתובת `http://<synology-ip>:21114`.
- [ ] תוך כ-30 שניות המכשיר מופיע בעמוד המכשירים עם נקודה ירוקה.
- [ ] סוגרים את ה-client ותוך כ-30 שניות הנקודה הופכת לאפורה.
- [ ] ב-client: Login עם המשתמש admin. ה-client מציג את שם המשתמש, ובקונסול העמודה "משתמש משויך" מציגה admin.
- [ ] יוצאים מהחשבון ב-client, והשיוך נשאר בקונסול.
- [ ] מתחברים 11 פעמים עם סיסמה שגויה ומקבלים הודעת חסימה.
- [ ] חיבור מרחוק רגיל בין שני מחשבים עובד כמו לפני השדרוג.
- [ ] בדפדפן: מעבר בין עברית לאנגלית מהפך את כיוון הממשק (ימין לשמאל ולהפך).

## איך מריצים שוב את הבדיקה האוטומטית

מתוך תיקיית הפרויקט (דורש Rust, ו-Python 3; אם `console-ui/dist` חסר הסקריפט בונה אותו):

```
python -I docs/webconsole/phase1-acceptance-check.py
```

בלי בנייה מחדש (אם כבר נבנה):

```
python -I docs/webconsole/phase1-acceptance-check.py --skip-build
```

הסקריפט עובד על Windows בלבד, ודורש Rust (cargo) ו-Node עם npm (npm נדרש רק אם `console-ui/dist` חסר).

הסקריפט מפעיל שרת זמני על פורטים 21114 עד 21119, לכן צריך לוודא שאין hbbs/hbbr אחרים רצים. הוא מדפיס PASS או FAIL לכל בדיקה ומוחק אחריו את הקבצים הזמניים. הסקריפט משתמש גם ב-`E:\RustDesk\res\devices.py` ואפשר לשנות נתיב עם `--devices-py`.
